## Wzory (reguły z jego poprawek)
- zaimek 1. os. "ja" (osoba) → **jo**; "ja" = tak (stare wpisy zostają)
- 3. os. l.mn. -ą → **-om** (skończą → skonczom), lecą → **loto**
- wykończ-/skończ- → **wykonczyć / skonczyć** (ń/ń → n, ó przed cz → o)
- 1. os. lp.: -am / -om → **-a** (wciepuja, połoncza)
- -aje → **-owo** (dodowo, wydowo)
- -enie → **-yniy** (sprawdzyniy)
- ą przed spółgłoską → **on** (połoncza)
- możesz → **mogesz**
- bezokolicznik -nąć → **-nyć** (wciepnyć)
- narzędnik -em → **-ym** (kupnym)
- dopełniacz -ego → **-ygo** (nowygo)
- -ania → **-anio** (snejpowanio)
- snajp- → **snejp-**
- e przed m w zapożyczeniach → **y** (chemia → chymia)
- czas przeszły -azł / -ał → **-oz / -oł** (wylazł → wyloz, znalazł → znaloz/znalozł, zrobił → zrobiył/zrobił — sprawdzaj u niego)
- naj- → **noj-**, -ier- → **-iyr-** (nojpiyrw, nojlepszy); dla → **do**
- cena = **cyna** (żeńska: ta cyna, tej cyny, cyny l.mn.); czas przeszły żeński -ęła → **-yna** (wziyna)
- nagłówki tabel i etykiety tyż po naszymu (Kaj, Wiela, Kiej), niy ino zdania
- "sie" przed czasownikiem: "sie samo zrobi", nie "zrobi sie sama"; "samo" (nijaki) w "samo sie zrobi"
- czas przeszły 2. os. lp. skracany: -nąłeś → **-es** (wciepnyłeś → wciepes; do potwierdzenia przy innych czasownikach)
